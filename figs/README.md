# figs/ —— 图表说明

本目录放**结果性图表**（曲线、对比、混淆矩阵）。共 8 张，全部由 `data-Project1/plots.py` 从 `../results/` 的 CSV 生成：

```bash
cd ../data-Project1
python plots.py                 # 全部重生成
python plots.py --only fig4     # 只重生成某一张
```

## 与 figs/term/ 的分工

| 目录 | 类型 | 覆盖什么 |
|---|---|---|
| **`figs/`**（本目录） | 结果性图表 | 分数、曲线、对比、分布——**"结果是什么"** |
| **`figs/term/`** | 终端证据截图 | 命令与输出——**"结果是怎么来的"** |

两者合起来才构成完整的证据：图给出结论，截图给出结论的来路。

## 图表规范（自己定的，新图要遵守）

1. **配色是算出来的，不是挑出来的。** 分类色板取自一套验证过的调色板，按固定槽位顺序取用、不循环。4 色组合跑过验证器：亮度带、色度下限、CVD 分离度、正常视觉分离度全部 PASS。
2. **低对比度的颜色必须配可见标签。** 验证器对 aqua（2.74:1）和 yellow（2.11:1）报 WARN——低于 3:1。所以**所有柱子上都直接标了数值**，这是补偿要求而不是装饰。信息永远不靠颜色单独承载：森林图里"显著/不显著"同时用实心/浅色 + 数值 + 图例说明。
3. **顺序编码只用单一色相**（混淆矩阵用蓝色由浅到深），绝不用彩虹色。
4. **差异远小于轴跨度时画 Δ 而不是绝对值。** 清洗阶梯 7 个配置的差异只有 0.006~0.031，画在 0.86~0.94 的纵轴上柱子几乎等高，"每加一步就往下走"根本看不出来。改画 Δ 后一眼可见。
5. **"精确估计 + 不确定性"用点区间图，不用柱状图。** 柱状图用长度编码数值，纵轴一旦不从 0 起就会放大差异（经典反模式）；点区间图用位置编码，截断轴不构成失真。fig1 因此从柱状图改成了点区间图。
6. **纵轴范围不同必须在图里说明**（fig5 两个子图一个是 0.90~0.95、一个是 0~0.95）。
7. **渲染出来实际看一眼再收工。** 验证器只管颜色，不管排版——实际看图之后才发现并修掉了三处问题：标题压在副标题上、Δ 标签与柱子同色导致完全看不见、fig1 用柱状图配截断轴。

> 第 7 条不是形式。那三处问题在代码里都"看起来对"，只有渲染出来才暴露。
