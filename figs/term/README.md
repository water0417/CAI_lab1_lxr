# figs/term/ —— 终端证据截图

## ✅ 已自动生成，无需手动截图

本目录下 12 张 PNG 由脚本从 `results/` 的运行日志渲染而成：

```bash
cd ../../data-Project1
python make_term_shots.py          # 重新生成全部 12 张
python make_term_shots.py 3 6      # 只重生成指定编号
```

**关于真实性**：图片内容是日志文件的**原样输出**（含耗时、警告、文件路径）；
脚本只做"过滤显示范围 + 配色渲染"，**不增删任何一个字符**。
每张图的正文第一行就是产生它的命令，可据此自行复现核对。
